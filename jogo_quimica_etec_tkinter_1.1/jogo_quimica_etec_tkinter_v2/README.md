
# Química Experimental - ETEC

Versão atualizada do jogo educacional em Python com Tkinter.

## Melhorias da versão 2

- Removido o nome "LabQuest" da tela de login.
- Interface visual melhorada.
- Botões com efeito visual ao passar o mouse.
- Alternativas em formato de cards clicáveis.
- Tela de ranking geral.
- Tela para o professor visualizar usuários cadastrados.
- Após cadastrar uma questão, o professor é direcionado para a lista de questões cadastradas.

## Como executar

Abra o terminal dentro da pasta do projeto e execute:

```bash
python main.py
```

ou:

```bash
py main.py
```
