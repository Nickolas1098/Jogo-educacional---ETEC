
# LabQuest ETEC - Jogo de Química em Python com Tkinter

Projeto desktop desenvolvido em Python para apoiar alunos do 1º ano do curso técnico em Química na identificação de materiais de laboratório, suas funções e associação com sistemas experimentais.

## Objetivo

O jogo ajuda estudantes a praticarem:
- identificação de vidrarias e materiais de laboratório;
- associação entre material e função;
- associação entre sistema experimental e materiais utilizados;
- aprendizagem progressiva por níveis de dificuldade.

## Identidade visual

O projeto utiliza uma identidade visual inspirada no Centro Paula Souza e na ETEC Júlio de Mesquita:
- vermelho institucional;
- cinza grafite;
- fundo claro;
- interface simples e adequada para estudantes do ensino médio.

Referências:
- Manual de identidade visual do CPS
- Site da ETEC Júlio de Mesquita

## Funcionalidades

### Aluno
- Login e cadastro;
- Responder perguntas de múltipla escolha;
- Usar dica nas questões;
- Visualizar pontuação final;
- Registro automático do desempenho.

### Professor
- Login e cadastro;
- Cadastro de novas questões;
- Visualização das questões cadastradas;
- Relatório básico de desempenho dos alunos.

## Tecnologias

- Python 3
- Tkinter
- SQLite

## Como executar

1. Instale o Python 3.
2. Extraia a pasta do projeto.
3. Abra o terminal dentro da pasta.
4. Execute:

```bash
python main.py
```
